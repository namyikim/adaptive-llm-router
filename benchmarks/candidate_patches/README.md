# Externally generated L2/L3 candidate patches

This directory initially contains NO patches. Never treat a placeholder or assistant-invented patch as a measured L2 or L3 model result.

After independently providing the identical task prompt to the chosen target models, save the actual unified diffs to:

- `CASE_ID/l2.patch` — patch genuinely generated by the exact documented L2 model
- `CASE_ID/l3.patch` — patch genuinely generated by the exact documented L3 model

`CASE_ID` must be one of `tqdm-6`, `tornado-5`, `tornado-6`, `tornado-7`, `tornado-11`, `tornado-14`. The public historical bug tester requires explicit workflow `execute=true`, a real `model_id`, and a real submitted patch. No paid API invocation occurs in the verifier. Do not submit secrets or proprietary code to this public repository.

Details and CLI: [L2/L3 evaluation guide](../../docs/bugsinpy-l2-l3-patch-evaluation.md).
